# Face Detection System

## About the Project
This is a Face Detection project developed using Python and OpenCV. 
The system detects human faces in real-time using a webcam.

## Features
- Real-time face detection
- Webcam integration
- OpenCV-based implementation
- Fast and accurate detection

## Technologies Used
- Python
- OpenCV
- NumPy

## How to Run
1. Install Python
2. Install OpenCV:
   pip install opencv-python
3. Run the Python file

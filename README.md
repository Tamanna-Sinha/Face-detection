# Face Detection System

## About the Project
This is a Face Detection project developed using Python and OpenCV. 
The project detects human faces from images captured using the IP Webcam application on a mobile phone.

## Features
- Face detection from captured images
- Image processing using OpenCV
- Mobile IP Webcam image input
- Accurate face recognition using computer vision techniques

## Technologies Used
- Python
- OpenCV
- NumPy
- IP Webcam (Mobile App)

## Working Process
1. Capture images using the IP Webcam app on a mobile phone.
2. Transfer or access the images.
3. Process the images using Python and OpenCV.
4. Detect faces in the image.

## Project Output
The system identifies and highlights faces present in the provided images.
